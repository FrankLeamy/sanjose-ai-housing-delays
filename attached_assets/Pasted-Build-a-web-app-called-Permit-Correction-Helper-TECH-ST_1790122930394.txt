Build a web app called "Permit Correction Helper"

TECH STACK
- Frontend: React
- Backend: Node.js + Express
- Database: SQLite
- No login or user accounts
- Clean, simple, mobile-friendly design

WHAT IT DOES
- User uploads a City permit correction letter (PDF, PNG, or JPG)
- App extracts the text, sends it to an AI model, and shows a report of which City comments are met and which need fixing
- The app never approves or rejects permits

UPLOAD PAGE
- File upload field (PDF, PNG, JPG)
- "Analyze Letter" button
- Loading message while processing
- "Try a sample" button that lets the user pick one of the sample letters (sample text is sent directly to the AI, skipping text extraction)

TEXT EXTRACTION
- PDFs: extract text with pdf-parse
- Images (PNG/JPG): run OCR with tesseract.js
- Scanned PDFs with no text: convert pages to images first, then run tesseract.js

AI ANALYSIS
- Send the letter text and the "rules" from criteria.json to the AI
- Ask the AI to return only JSON with these fields:
  - project
    - address
    - summary
  - items (one for each City comment)
    - comment: the City's original comment
    - status: "met" or "needs_fix"
    - how_to_fix: what the applicant should do
    - department: which City department made the comment
    - category: must match a category in criteria.json
    - unclear: true or false
- If the category isn't in criteria.json, use "Uncategorized"
- Save the results in SQLite
- If something goes wrong, show a friendly error and a "Try Again" button


REPORT PAGE
- Top: highlighted box with the text "This report is generated by AI and does not guarantee permit approval."
- Project info: address, summary
- Section A – Items That Are Met
  - Checklist grouped by department
- Section B – Items That Need to Be Fixed
  - Checklist grouped by department
  - Show "how to fix" for each item
  - If unclear is true, highlight the item with: "This comment is unclear. Contact your City reviewer."
- Every item has a checkbox for tracking progress (save checkbox state in SQLite)
- Bottom: "Download Report" button that saves the report as a PDF using html2pdf.js

FAKE NOTIFICATIONS (demo only)
- After analysis, show a pop-up:
  - All items met: "Good news! Your submission appears complete."
  - Otherwise: "Your submission needs changes. See the items below."
- Bell icon in the header that lists past notifications (stored in SQLite)

CRITERIA FILE (criteria.json)
- Note at the top saying these are placeholders
- App reads this file at runtime so it can be edited without changing code
- "categories":
  - Missing site plan details
  - Zoning or setback issue
  - Stormwater or grading info missing
  - Fire access requirement
  - Parking requirement
  - Missing signature or stamp
  - Missing documents or fees
  - Height or story limit
  - Floor area ratio (FAR)
  - Riparian/creek setback
  - Historic resource
  - Impervious surface
  - Second-story addition
  - Front porch
  - Attached garage
  - Design consistency
- "rules" (passed to the AI as review context):
  - Flag if a new house or addition exceeds 30 feet or 2 stories
  - Flag if FAR exceeds 0.45
    - FAR counts all floors of the main structure measured to outside walls, including stairwells and areas more than 50% enclosed and covered
    - FAR excludes garages, basements, accessory structures, and ADUs
  - Flag if construction is within 100 feet of a creek and the lot is 1/2 acre or larger
  - Flag if the site is on the City's Historic Resources Inventory (City Landmarks need a Historic Preservation Permit instead)
  - Flag if 10,000+ sq ft of impervious surface is created, replaced, or altered
  - Administrative review applies only if ALL of these are true:
    - No more than 50% of exterior walls removed
    - Height stays under 30 ft / 2 stories
    - Any second story is no more than 60% of first-floor area (including attached garage) and is set back an extra 10 ft from the front setback
    - Front porch is not enclosed or reduced by more than 10%
    - Attached garages only where neighboring lots have attached garages
    - Roofline, materials, and trim match the existing house (not required for ADUs)

SAMPLE LETTERS (/samples folder)
- 2 fake correction letters as .txt files:
  - sample-mostly-met.txt: most items are met
  - sample-needs-fixes.txt: several items need fixing (e.g., FAR over 0.45, second story too large, missing stamp)
